# Changelog

## 1.0.0 — 2026-10-12
First public release.
- Data: latitude/longitude (DMS or decimal), true-north compass, satellites used/visible,
  accuracy, time to first fix, last fix, speed, altitude above mean sea level, plus code;
  copy and share.
- Map: OpenStreetMap with heading arrow, accuracy circle, trail, re-center.
- Offline maps: built-in world map, plus downloadable country/state maps from
  download.mapsforge.org. Used whenever there is no working internet, and to fill in tiles
  that fail to download while online.
- Compass: full-screen dial, true/magnetic north, calibration warning.
- Android Auto: map with speed/course/altitude/coordinates/satellites and a compass view.
- Updates itself from this repository's GitHub releases.
